# 🌸 About Veeru

Veeru is an intelligent AI companion built to make conversations feel natural, comforting, and engaging.

Whether you're feeling lonely, need motivation, want productivity assistance, or simply wish to have someone to talk to—Veeru is always there.

Designed with a beautiful modern interface and powered by advanced AI, Veeru delivers an experience that feels personal, warm, and interactive.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/username/Veeru.git
```

Move into Project

```bash
cd Veeru
```

Install Packages

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Preview

```bash
npm run preview
```
