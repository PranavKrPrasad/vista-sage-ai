# ❤️ Veeru – Your AI Partner

Veeru is an AI-powered virtual companion designed to provide meaningful conversations, emotional support, productivity assistance, and personalized recommendations. Whether you need someone to chat with, organize your day, or simply brighten your mood, Veeru is always available.

## 🌐 Live Demo

https://veeru-your-partner.lovable.app

---

## ✨ Features

- 🤖 AI-powered conversational assistant
- 💬 Natural and human-like conversations
- ❤️ Emotional support and companionship
- 📅 Daily planning and productivity assistance
- 🎯 Personalized suggestions and recommendations
- 🌙 Beautiful, responsive, and modern UI
- 🔒 Secure and privacy-focused
- 📱 Mobile-friendly design
- ⚡ Fast performance with real-time interactions

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/veeru.git
```

### Navigate into the project

```bash
cd veeru
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```
